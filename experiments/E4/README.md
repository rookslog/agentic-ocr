# E4 — The structure question (A2 vs A1)

**Status:** prereg pending · run order: Phase 3, first of the agentic experiments.
**The heart of the research question.**

**Hypothesis (one line).** Bounded verify→revise loops on L2/L3 structure (C2) beat
single-pass structure emission by **≥10 points** on footnote-anchoring /
reading-order / section metrics, at acceptable cost, with transcription held frozen.

The hypothesis comes from ParseBench (+22 grounding) and lab priors — both flagged
**non-transferable** from enterprise docs to scholarly books (PLAN §2.4).

**Pre-registered disconfirmer.** Δstructure < the pre-set margin (margin fixed once
metric variance is known from E2) ⇒ the agentic dividend does **not** transfer from
enterprise documents to scholarly books — *a publishable negative answer to the
research question.*
