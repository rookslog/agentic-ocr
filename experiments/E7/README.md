# E7 — Open-agent probe (A3)

**Status:** prereg pending · run order: **last**, VOI-gated, smallest experiment.

**Hypothesis / purpose (one line).** Run C3 (an agent with tools — re-OCR region,
compare engines, consult ToC, look ahead/behind) on a small hard-stratum sample
**purely to mine error classes C2 misses**. No throughput claims are made.

**Pre-registered kill criterion (the disconfirmer).** If C3 finds **no error class
that C2 misses**, then A3 is **closed for this domain** and recorded as such — the
open agent does not earn its 4–8× token multiplier here.

This experiment runs only if the value-of-information gate from E4/E5 justifies it,
and is deliberately the smallest and last (PLAN §1: A3 prediction is that it fails
the cost gate at 200 books/day).

Full pre-registration → `prereg.md`. Derived from PLAN.md §9 E7.
